LearnOS 当前状态：三个独立系统

学习计划、艾宾浩斯复习、智能分析——各自独立运行

📋 学习计划

学生手动创建计划：填标题、选科目、设日期、选时长

→ 周视图显示计划分布

→ 点击「开始」启动番茄钟

❌ 不关联知识点

🧠 艾宾浩斯复习

唯一入口：手动创建知识点

学生手动录入：名称、科目、难度1-5、重要性1-5、描述、来源

→ 系统自动生成复习记录

→ 看板显示今日/本周待复习

❌ 和学习计划无关联（source_kp_id 从未在前端填充）

❌ 复习就是复习，不知道为什么复习、跟哪个计划相关

📊 智能分析

5因子评分：完成率低 + 掌握度低 + 情绪差 + 目标差距 + 复习逾期

→ 生成薄弱科目排行

→ 生成建议 Insights

❌ 分析结果是静态的，不会自动调整学习计划

❌ 建议是文本，不会自动创建任务

核心问题：数据流断裂

计划创建 → 番茄钟 → 复盘 → ??? → 知识点？

知识点创建 → 复习记录 → SM-2排程 → ??? → 计划？

分析结果 → Insights → ??? → 影响行为？
